# Jev private-message routing

Install with `qwenpaw plugin install plugins/tool/jev-private-routing`, then restart DClaw. Set `TYPESAFE_API_KEY` in the DClaw server process environment. The key is read at call time and is never passed to the Agent prompt or stored in its workspace. The plugin uses the domestic relay `https://api.aijiau.com/v1/systemone` as its default primary channel; deployments can override the complete endpoint with `TYPESAFE_API_URL`. Set `TYPESAFE_RELAY_TOKEN` when the primary channel requires the `X-DClaw-Relay-Token` header.

The plugin supports an optional independent fallback channel through `TYPESAFE_FALLBACK_API_URL`, `TYPESAFE_FALLBACK_API_KEY`, and `TYPESAFE_FALLBACK_RELAY_TOKEN`. Both fallback URL and key are required when any fallback setting is present. The primary channel is always attempted first. Network failures, timeouts, authentication or balance failures, rate limits, regional restrictions, server errors, and malformed provider responses switch to the fallback channel. Request-contract errors such as HTTP 400 or 422 fail immediately because replaying the same invalid request would only duplicate cost. Channel failures are logged by channel name without credentials.

Jev is a plugin-owned decision dependency, not a DClaw platform model. Do not register Jev in the platform provider/model catalog or route it through the general Agent model selector. Endpoint selection, credentials, failover, request construction, and response validation must remain inside this plugin package. The Agent and Bot Server consume only the plugin's stable routing result.

Only `douyin_engagement_agent` enables `route_private_message_jev` in its `agent.json`. Plugin registration adds a disabled entry to other Agent profiles. Each schema v2 candidate contains an opaque `routingContext` string composed by the caller, plus `taskId`, `routingThreshold`, and `routingMinMargin`. DClaw passes `routingContext` to Jev unchanged and does not understand its business fields. This keeps future evidence changes in the caller and prevents reply goals or lead rules from being added implicitly. Schema v1 candidates remain supported during rolling upgrades. The tool batches up to 2,000 candidates and compares batch winners globally.

The tool calls TypeSafe `POST /v1/systemone` with `jev-latest` and a Choice with `no_match`. It batches more than 200 tasks, supports at most 2,000, and globally compares batch winners. Weak probabilities, missing credentials, and API failures cannot produce a task selection. Each task supplies its own acceptance threshold; thresholds should be calibrated against labeled Douyin messages before broad rollout.

# Jev private-message routing

Install with `qwenpaw plugin install plugins/tool/jev-private-routing`, then restart DClaw. Set `TYPESAFE_API_KEY` in the DClaw server process environment. The key is read at call time and is never passed to the Agent prompt or stored in its workspace. The plugin uses `https://api.typesafe.ai/v1/systemone` by default; deployments that require a regional relay can override the complete endpoint with `TYPESAFE_API_URL`. Set `TYPESAFE_RELAY_TOKEN` when the relay requires the `X-DClaw-Relay-Token` header.

Only `douyin_engagement_agent` enables `route_private_message_jev` in its `agent.json`. Plugin registration adds a disabled entry to other Agent profiles. The tool accepts the latest private message, optional shared-video metadata, same-conversation history, and Bot Server candidate tasks containing routing metadata, target-video share text, and task-specific confidence controls. Target-video share text contributes author, title, hashtag, and URL evidence without exposing reply goals or lead rules. It batches up to 2,000 candidates and compares batch winners globally.

The tool calls TypeSafe `POST /v1/systemone` with `jev-latest` and a Choice with `no_match`. It batches more than 200 tasks, supports at most 2,000, and globally compares batch winners. Weak probabilities, missing credentials, and API failures cannot produce a task selection. Each task supplies its own acceptance threshold; thresholds should be calibrated against labeled Douyin messages before broad rollout.

# 项目介绍

本页说明 QwenPaw 是什么、能做什么、以及如何按文档一步步上手。

---

## QwenPaw 是什么？

QwenPaw / DClaw 是一款部署在你自己环境中的**企业 AI 工作台与多智能体执行平台**。

![控制台](https://img.alicdn.com/imgextra/i1/O1CN01ikrU3k1TRdNESHtzV_!!6000000002379-2-tps-3822-2070.png)

- **任务工作台** — 发起任务、挂载资料、选择智能体/技能/专家团队，并追踪执行状态和结果。
- **多智能体协作** — 支持创建多个独立智能体，每个智能体拥有独立配置、记忆和技能，还可以与专家团队协同完成复杂任务。
- **AIGC Studio** — 通过画布化节点组织脚本、图片、视频、音频和参考资产，串联内容生产流程。
- **企业知识库** — 支持本地文档、企业知识、飞书/Lark 云文档接入，并结合关键词与语义检索复用知识。
- **模型、插件与 MCP** — 支持多模型提供商、Skills、插件和 MCP 工具，把模型能力接入真实业务系统。
- **治理与安全** — 内置用户与角色、会话审计、Token 用量、工具防护、文件访问控制、对象存储和备份恢复。
- **多端触达** — 控制台、桌面端、小程序以及钉钉、飞书、Discord、Telegram 等频道按场景接入。

QwenPaw 由 [AgentScope 团队](https://github.com/agentscope-ai) 基于
[AgentScope](https://github.com/agentscope-ai/agentscope)、
[AgentScope Runtime](https://github.com/agentscope-ai/agentscope-runtime) 与
[ReMe](https://github.com/agentscope-ai/ReMe) 构建。

## 你怎么用 QwenPaw？

使用方式可以概括为五类：

1. **在 Workbench 发起任务**
   输入目标、上传附件、选择智能体/技能/专家团队，系统创建可追踪的任务执行流。

2. **在 AIGC Studio 生产内容**
   用画布节点组织脚本、图片、视频、音频和参考资产，按模型能力生成或编辑素材。

3. **在知识库中检索和复用**
   上传企业文档、接入云文档，结合关键词与语义检索查找资料、生成摘要或引用上下文。

4. **让智能体协同执行**
   通过 Skills、插件、MCP 和专家团队连接外部工具、业务系统和自动化流程。

5. **通过多端和后台治理**
   在控制台、桌面端、小程序或业务频道中使用，并通过后台管理模型、用户、审计、用量和备份。

## 文档中会出现的几个概念

- **控制台** — QwenPaw 内置的 Web 管理界面，可以在控制台中对话、配置频道、管理技能、
  设置模型等。详见 [控制台](./console)。
- **频道** — 你和 QwenPaw 对话的「场所」（钉钉、飞书、QQ、Discord、iMessage 等）。在
  [频道配置](./channels) 中按步骤配置。
- **心跳** — 按固定间隔用你写好的一段问题去问 QwenPaw，并可选择把回答发到你上次使用的
  频道。详见 [心跳](./heartbeat)。
- **定时任务** — 多条、各自独立配置时间的任务（每天几点发什么、每隔多久问 QwenPaw 什么等），
  通过控制台或 [CLI](./cli) 管理。
- **技能池与工作区技能** — 技能池是共享的技能仓库，工作区技能是某个智能体真正运
  行时使用的技能副本。详见 [Skills](./skills)。
- **MCP 和工具** — MCP（Model Context Protocol）是一种标准协议，允许接入外部
  工具服务器扩展能力。工具是 QwenPaw 内置的基础能力（如读写文件、执行命令、
  浏览器等）。详见 [MCP和工具](./mcp) 。
- **智能体/工作区** — 从 v0.1.0 开始，QwenPaw 支持多智能体，允许运行多个独立的
  AI 智能体。每个智能体拥有独立的工作区、配置、记忆、技能和对话历史，智能体之间
  还可以通过协作技能互相通信、共同完成复杂任务。详见 [多智能体](./multi-agent)。
- **安全机制** — QwenPaw 提供多层安全防护，包括工具防护（拦截危险命令参数）、
  文件防护（限制敏感路径访问）、技能扫描器（检查技能包安全性）等。详见 [安全](./security)。

各概念的含义与配置方法，在对应章节中均有说明。

## 建议的阅读与操作顺序

1. **[快速开始](./quickstart)** — 用三条命令把服务跑起来。
2. **[控制台](./console)** — 服务启动后，在浏览器中打开控制台（`http://127.0.0.1:8088/`），
   **这是配置与使用 QwenPaw 的中心枢纽**。先在控制台体验对话、配置模型，有助于理解
   QwenPaw 的工作方式。
3. **[模型](./models)** — 配置云端 LLM 提供商的 API Key，或下载本地模型。这是使用
   QwenPaw 的**必要前提**。
4. **按需配置与使用**：
   - [频道配置](./channels) — 接入钉钉 / 飞书 / 微信 / Discord / Telegram 等，在对应 app 里与 QwenPaw 对话；
   - [Skills](./skills) — 了解与扩展 QwenPaw 能力；
   - [MCP和工具](./mcp) — 接入外部 MCP 工具服务器；
   - [魔法命令](./commands) — 使用特殊命令快速控制对话状态（如 `/new` 开启新对话、`/clear` 清空历史、`/stop` 停止任务、`/restart` 重启服务等），无需等待 AI 理解；
   - [安全](./security) — 配置工具防护、文件防护、技能安全扫描等安全机制；
   - [心跳](./heartbeat) — 配置定时自检或摘要（可选）；
   - [定时任务](./console#定时任务) 或 [CLI](./cli) — 管理定时任务、`qwenpaw doctor` 诊断与 `qwenpaw doctor fix`、清空工作目录等；
   - [多智能体](./multi-agent) — 多智能体配置、管理与协作（v0.1.0+ 新功能）；
   - [配置与工作目录](./config) — 工作目录与配置文件说明。

# 源行为基线

## 来源

源平台是 DClaw 普通 Agent 工作区，源版本由 `workspace/skill.json` 记录为业务技能
1.1.0、Jev 路由技能 1.0.0。源材料位于同项目 `workspace/`，只作迁移证据。

## 可回归行为

| 场景 | 前置状态与输入 | 源工具/服务 | 状态变化 | 输出与完成判据 | 确认度 |
|---|---|---|---|---|---|
| 健康检查 | 合法协议 | 无 | 无 | 固定能力版本 2 | confirmed |
| 生成评论树 | 数量、层级、窗口、业务意图 | 模型 | 无 | 精确数量、合法依赖、父先子后 | confirmed |
| 修复评论树 | 原树和校验问题 | 模型 | 无 | 合同合法且尽量保留意图 | confirmed |
| 依赖丢失恢复 | 附近评论列表 | 模型 | 无 | 附近回复或新一级评论，不能空结果 | confirmed |
| 私信归因成功 | 当前消息、同会话历史、候选 | Jev 平台工具 | 无 | 原样返回候选 ID、概率和置信度 | confirmed |
| 私信归因不明 | 问候或候选接近 | Jev 平台工具 | 无 | `UNRESOLVED`，不强行归因 | confirmed |
| 私信回复 | 当前会话与业务目标 | 模型 | 无 | `REPLY` 或 `NO_REPLY` 严格 JSON | confirmed |
| 线索规则命中 | 入站原文满足规则 | 模型 | 无 | 逐字证据和连续线索子串 | confirmed |
| 信息不足 | 缺少协议段或候选证据 | 无/模型 | 无 | 失败关闭或 `UNRESOLVED` | confirmed |
| 第三方失败 | Jev API 出错 | Jev 平台工具 | 无 | `ERROR`，不选择任务 | confirmed |
| 重试/断线 | 同一请求再次进入 | 普通 Agent/OpenAPI | 未定义持久业务状态 | 不得产生抖音副作用 | partial |
| 人工介入 | 归因不明 | Bot Server 后续澄清 | 外部流程 | 中性询问视频来源 | confirmed |
| 无工具普通对话 | 非三段协议 | 无 | 无 | 不受支持，应拒绝 | confirmed |

## 未知行为

- 除数量、层级、`startsAt` 和 `endsAt` 外，源系统时间间隔与分散度字段的准确名称
  和算法为 `unknown`。
- Jev `confidence` 的精确统计定义为 `unknown`；目标实现将其视为相对下一结果的置信差，
  并以候选 `routingMinMargin` 作失败关闭门禁。
- 源 OpenAPI 断线后的平台级 invocation 重放语义为 `unknown`；专家本身无外部副作用。

## 对比准则

允许文案措辞变化；操作枚举、JSON 结构、任务 ID、不变量、失败关闭和“不得宣称已
执行抖音动作”必须一致。移除 Jev 平台插件属于架构迁移，业务阈值门禁保留在专家内。

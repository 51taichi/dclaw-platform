# 旧入口兼容说明

`migration` 是旧版 Skill 对“使用已有材料首次发布新专家”的模式名称。当前版不再把它作为独立路径；请按 [统一开发流程](new-development.md) 的“使用现有材料起步”继续。

旧项目记录和 Issue 中的 `migration` 字段保留历史含义，不批量改名或重做有效测试。继续工作时记录当前使用 `new-development`，引用原件保护、副本、行为基线和已放行节点证据；从首个未放行或受影响节点接续。已发布同一专家的更新仍按 [optimization](optimization.md) 处理。需要核对旧版原文时读取 Git 标签中的 `v1.9.4:references/migration.md`，不把本兼容页当成当时的规则原文。

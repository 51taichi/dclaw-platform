## 📝 记录规范

### ✅ 应该记什么
- **状态变更**：技术栈切换、配置更新、环境迁移
- **用户偏好**：编码风格、命名约定、工具使用习惯
- **高价值经验**：通用解决方案、踩坑教训、可复用模式

### ❌ 不应该记什么
- 流水账式任务记录
- Bug 修复的具体细节（保留方法论即可）
- 单次任务的执行步骤

## 🗑️ 维护策略

| 操作 | 触发条件 |
|------|----------|
| **覆写** | 状态变更时，用新值替换旧值 |
| **合并** | 发现相似条目时，提炼为通用规则 |
| **删除** | 已被证伪的假设或不再适用的内容 |

## ⚡ 高价值经验沉淀

### 调试方法论
1. **日志分层**: INFO/WARN/ERROR三级分离，避免信息过载
2. **断点策略**: 优先在数据流转节点设置监控点
3. **回滚机制**: 生产变更必须准备可逆方案

### 代码质量红线
- 核心逻辑单元测试覆盖率 ≥80%
- PR 必须包含测试用例增量
- 禁止直接删除生产环境数据（需审批流程）

### 性能优化原则
- 数据库查询增加索引覆盖
- API 响应时间控制在合理区间（关注P95/P99）
- 静态资源启用CDN缓存
- 长任务异步化队列处理

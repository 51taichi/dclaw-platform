## 核心原则

### 记忆优化准则
1. **极简去冗**：仅保留核心业务决策、确认的用户偏好、高价值可复用经验；拒绝流水账/Bug修复细节/单次任务记录
2. **状态覆写**：技术栈变更/配置更新时，新状态直接替换旧状态，严禁新旧矛盾信息并存
3. **归纳整合**：零碎相似规则提炼为通用性强的独立条目
4. **废弃剔除**：主动删除已证伪假设或不再适用陈旧条目

### 记录范围
- ✅ 技术栈决策与架构演进
- ✅ 业务关键决策与优先级调整
- ✅ 用户偏好确认（界面/功能/行为）
- ✅ 高价值经验教训（可复用模式）
- ❌ Bug修复过程细节
- ❌ 单次任务执行记录
- ❌ 临时性配置变更

## 工具设置

### Skills 定义工具使用规范
**用途**：记录 Agent 专属工作区配置，作为技能执行时的上下文参考

### 可记录内容类型
| 类别 | 示例 | 说明 |
|------|------|------|
| **环境连接** | SSH 主机别名与凭证 | 服务器访问信息 |
| **工具依赖** | API密钥/服务账号 | 跨任务复用配置 |
| **工作流偏好** | 代码风格/命名规范 | 统一输出标准 |
| **业务规则** | 权限模型/数据约束 | 领域特定逻辑 |

### 记录格式规范
```markdown
### [分类名称]
- 条目1：详细说明（含适用场景）
- 条目2：注意事项（含限制条件）
```

## 维护说明

- **更新频率**：每次重大决策或模式确认后即时更新
- **验证机制**：删除前确认是否已被新方案替代
- **冲突处理**：新旧信息共存时以最新状态为准并标注变更时间线

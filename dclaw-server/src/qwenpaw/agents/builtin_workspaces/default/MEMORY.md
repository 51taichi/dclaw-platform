## 维护原则

**极简去冗**: 仅保留核心决策、确认偏好与高价值经验，严禁流水账与单次任务细节。

**状态覆写**: 新信息覆盖旧信息，避免矛盾并存。

**定期清理**: 移除无实质内容的占位符，保持文件精简。

## 项目启动流程

1. **询问技术栈约束**: 语言版本、框架偏好
2. **确认依赖管理方式**: npm/pnpm/yarn/docker等
3. **了解现有代码结构**: 目录组织、命名规范
4. **特殊要求**: 用户禁忌或强制规范

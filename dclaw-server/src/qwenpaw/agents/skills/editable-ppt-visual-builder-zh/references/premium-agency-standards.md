# Premium Agency Standards Reference

Use this reference when the deck is meant to feel like work from a top-tier presentation design studio, executive communications team, or strategy/design agency.

## Core Standard

Top-tier presentation work is not slide decoration. It is a controlled production process:

- clear creative brief
- sharp strategic message
- approved storyboard
- distinctive visual direction
- systematic typography, layout, and components
- custom graphics and information design
- editable production file
- full-size visual QA
- delivery notes and final signoff

## Creative Brief

Before design production, define:

- audience and decision-maker
- situation and business stakes
- desired belief shift
- required decision or action
- presentation setting: sent ahead, live meeting, keynote, sales call, board review, investor pitch, training, or template system
- presenter constraints: with speaker, self-reading, bilingual, remote screen share, printed PDF, or mobile review
- brand constraints: logo, color, fonts, imagery, tone, templates, legal notes
- mandatory content and forbidden claims
- proof requirements: data, screenshots, customer cases, quotes, implementation evidence, or placeholders
- success criteria and approval owner

If these inputs are missing, record assumptions and gaps. Do not invent client reality.

## Agency Review Gates

Use these gates for client-ready, investor, executive, sales, or high-stakes decks:

1. Creative brief gate: confirms objective, audience, tone, scope, and success bar.
2. Storyboard gate: confirms narrative sequence and slide roles before visual polish.
3. Visual direction gate: user selects one design direction before production.
4. Design system gate: confirms typography, grid, color, components, chart rules, and asset suite.
5. Production QA gate: checks full-size renders, editability, consistency, and content fidelity.
6. Delivery signoff gate: includes final PPTX, preview evidence, edit notes, missing-input caveats, and usage notes.

If the user has explicitly delegated a gate, record the delegation and decision rationale.

## Storyboard Standard

A storyboard is more than a list of slide titles. For each slide, define:

- audience question answered
- narrative beat
- claim
- proof object
- visual role
- emotional intensity
- expected action or takeaway
- whether it is an anchor, support, transition, or appendix slide

Do not enter final production if the storyboard is incoherent, repetitive, proof-light, or missing a decision path.

## Brand And Asset Audit

Audit:

- logos and lockups
- color tokens
- fonts and licensing
- product screenshots
- customer or case imagery
- diagrams or architecture references
- data sources
- icon library
- legal footnotes
- old template or master slide constraints

If missing, specify whether to omit, use a placeholder, generate a non-evidence visual, or request input.

## Master Layout System

Premium editable decks need layout governance. Define:

- cover layout
- section divider
- thesis/manifesto page
- executive summary
- evidence/chart page
- process/architecture page
- case proof page
- roadmap/timeline
- offer/ask page
- appendix/table page

For each layout, define margins, title zone, content zone, image zone, footer rules, page number rules, safe areas, and editable object rules.

## Delivery Package

For client-ready output, deliver or record:

- final editable PPTX path
- rendered contact sheet path
- full-size spot-check slide paths
- selected visual direction record
- font and fallback notes
- asset suite paths and usage notes
- edit guide: what is editable, what is raster, what should not be changed
- missing inputs and assumptions
- commercial readiness score and caveats

## Failure Patterns

- no creative brief, so the deck looks attractive but strategically generic
- storyboard skipped, so slides are pretty but the argument wanders
- visual direction selected but design system not extracted
- brand assets are missing but the deck pretends to be client-specific
- body slides are not governed by master layouts
- data and diagrams are styled but not designed to clarify decisions
- final deck is delivered without edit notes, caveats, or signoff evidence

# 已启用模型默认价格草案设计

**状态：** 已实现并通过最终验收

**日期：** 2026-08-30

**依赖：** `2026-08-30-admin-pricing-management-design.md`

## 1. 背景

生产环境尚未发布价格目录，OpenAPI 会在调用供应商前返回
`503 catalog_not_ready`。现有 Excel 导出只读取已经存在的可信成本记录，
当数据库尚无成本数据时只能导出空表，无法帮助管理员建立首份目录。

系统应从当前实际启用的平台及模型生成可编辑的价格草案，并尽可能预填经过
验证的官方参考成本。管理员调整、导入、预检和审批后发布不可变目录；Excel
本身不能直接改变正式计费规则。

## 2. 目标

- 导出当前已启用平台及其已开通模型，不再提供空白初始化模板；
- 按模型的真实计价维度逐行生成草案；
- 从版本化官方成本快照预填成本、来源及更新时间；
- 默认使用人民币成本的 `1.5` 倍作为建议销售价；
- 按 `1 元人民币 = 100 积分` 生成建议积分价格；
- 未匹配或缺少可靠价格的模型仍出现在 Excel，但默认不可发布；
- 允许管理员明确排除缺价模型，先发布其余完整模型；
- 首份目录发布后，已定价模型调用不再因目录整体为空返回
  `catalog_not_ready`。

## 3. 不做的事项

- 不根据相似模型名称猜测官方价格；
- 不在每次下载 Excel 时临时抓取供应商网页；
- 不把刷新得到的候选价格自动发布；
- 不把缺价模型按零价或免费模型处理；
- 不允许 Excel 绕过服务端价格计算、安全底价、审批或不可变目录；
- 不因某个缺价模型阻断其他已完整定价模型的发布。

## 4. 总体架构

系统由四个边界组成：

1. **启用模型清单**：读取当前已配置并启用的平台、内置模型和管理员已开通的
   额外模型；隐藏、禁用或缺少必要凭据的平台不进入草案。
2. **官方成本快照库**：保存版本化、可追溯的官方价格及换算证据；刷新只新增
   候选快照。
3. **价格草案生成器**：严格匹配模型身份，展开计价维度，应用默认倍率和积分
   换算，产生可导出及可预检的草案。
4. **现有审批发布链**：Excel 导入仅生成预检和草稿；管理员解决风险后才能发布
   不可变目录。

数据流如下：

```text
已启用平台和模型 + 官方成本快照 + 汇率快照
                    ↓
              价格草案生成器
                    ↓
        Excel 调整 / 导入 / 差异预检
                    ↓
          管理员审批 / 明确排除缺价项
                    ↓
               不可变价格目录
```

## 5. 启用模型清单

导出范围以系统当前配置为准：

- 百炼、火山引擎及其他内置平台只有在已启用并满足必要凭据条件时进入清单；
- 平台的内置可见模型与管理员开通的额外模型都进入清单；
- 被管理员隐藏或禁用的模型不进入本次草案；
- 清单记录平台 ID、平台名称、系统模型 ID、展示名称、模型类别和能力；
- 清单生成不访问外部网络，保证导出稳定。

价格库可以覆盖尚未启用的更多模型，但导出只包含当前清单中的模型。

## 6. 官方成本快照

每条快照至少保存：

- 平台 ID、官方模型 ID、模型版本或别名范围；
- 计价维度、官方单位和阶梯或规格条件；
- 官方原价和原币种；
- 汇率、汇率来源和换算时间；
- 换算后的人民币成本；
- 官方来源 URL、来源发布时间或页面更新时间；
- 采集时间、验证时间、验证状态和适配器版本；
- 有效期、优惠条件及账户级折扣适用条件；
- 快照版本和内容摘要。

价格来源按以下优先级产生候选：

1. 官方价格 API 或官方结算数据；
2. 经管理员验证的官方价格页面数据；
3. 经预检和审核的人工或 Excel 数据；
4. 上一份仍可信的已验证快照。

刷新可手动触发或按供应商周期运行，但只新增候选。来源失败时保留最后可信
快照并标记待复核，不影响已发布目录。

## 7. 严格模型匹配

已知平台按“平台 ID + 官方模型 ID”精确匹配。自定义平台或别名模型只有在管理员
配置明确的官方模型映射后才能采用官方价格。

- 不做模糊名称匹配；
- 不因名称相似自动继承其他平台或原厂价格；
- 聚合平台以实际结算平台价格为权威；
- 未匹配项仍导出，状态为“未匹配官方模型”，并默认不可发布；
- Excel 可提交映射候选，但服务端预检必须展示映射差异并要求确认。

## 8. 多维度计价

Excel 每一行表示“模型的一个计价维度”。同一模型可以有多行，例如：

- 文本/多模态：输入 Token、输出 Token、缓存读取、缓存写入；
- 图片：张数、尺寸、质量和编辑规格；
- 视频：时长、分辨率、帧率和是否带音频；
- 音频：字符、秒、分钟、输入或输出；
- Embedding/重排：Token、请求量或文档量；
- 供应商其他官方结算维度。

系统不得用单一综合价格代替官方维度。运行时用量无法映射到已发布维度时，应
拒绝计费调用或进入受控对账状态，不得猜测扣费。

## 9. 默认价格计算

默认草案计算为：

```text
建议人民币售价 = 已验证人民币成本 × 1.5
建议积分价格 = 建议人民币售价 × 100
```

计算使用高精度定点小数。`1.5` 是首次草案的默认销售倍率，不改变现有安全底价
校验；如果系统安全成本或最低服务价高于 1.5 倍结果，草案采用更高的安全底价并
明确标记原因。

管理员可以调整倍率或人民币成本。人工修改成本后必须提供来源或原因，状态变为
“人工价格待审核”，不得沿用官方验证标记。

## 10. Excel 工作簿

### 10.1 价格草案

包含：

- 平台名称、平台 ID；
- 模型名称、系统模型 ID、官方模型 ID；
- 模型分类、能力；
- 计价维度、官方单位和规格条件；
- 官方原价、原币种；
- 汇率、汇率来源、换算时间；
- 人民币成本；
- 默认或管理员倍率；
- 人民币销售价、积分价格；
- 官方来源 URL、来源更新时间、验证时间；
- 匹配状态、复核状态；
- 是否纳入本次发布；
- 管理员备注。

### 10.2 缺失与风险

汇总未匹配模型、缺失维度、过期来源、异常单位、低于安全底价、被排除模型及其
原因。该页由服务端生成，导入时重新计算，不能作为绕过校验的输入权威。

### 10.3 填写说明

说明可修改字段、只读身份字段、单位、倍率、积分换算和完整发布流程。服务端不
信任 Excel 公式或派生售价，所有金额在导入预检时重新计算。

## 11. 缺价模型与部分发布

- 缺价或未匹配模型默认阻止发布；
- 管理员必须补齐并审核价格，或逐项明确排除并填写原因；
- 明确排除后，其余完整模型可以发布首份目录；
- 被排除模型在计费入口返回稳定的“模型尚未定价”错误，不得按零价调用；
- 后续补齐价格时通过新目录版本纳入；
- 免费调用身份仍必须命中已审批规则，以保留报价和用量审计，只免除实际扣款。

缺价模型不得让已存在有效目录的其他模型重新退化为全局
`catalog_not_ready`。

## 12. 审批、发布与运行时

流程固定为：

```text
生成草案 → 导出/调整 → 导入校验 → 差异预检
→ 解决缺失与风险 → 管理员审批 → 发布不可变目录
```

- 重复导入相同文件保持幂等；
- 重复审批或并发发布只能产生一个获胜目录版本；
- 发布前再次读取模型清单，提示自草案生成后新增、禁用或变更的模型；
- 新请求锁定最新已生效目录，运行中请求继续使用旧目录；
- 正式目录只包含被批准纳入的模型和维度；
- 发布成功后执行只读探测，确认目录可锁定并报告仍未定价的模型；
- 不以真实客户调用作为发布探测，避免产生供应商费用。

## 13. 管理界面

目录为空时显示“生成首份价格草案”向导。向导展示：

- 已启用平台数、模型数和计价维度数；
- 已匹配、缺价、待复核和被排除数量；
- 当前默认倍率与积分兑换率；
- 官方价格快照版本和最近更新时间；
- 导出、导入预检、审批和发布入口。

正式发布后，页面继续支持生成增量草案和刷新官方价格候选，不再以空模板作为
主要入口。

## 14. 安全与审计

- 官方来源刷新身份无发布权限；
- 修改映射、人工成本、倍率、排除项、审批和发布必须使用计费保险锁；
- 审计记录包含前后值、来源、操作者、时间、IP、草稿、导入批次和目录版本；
- 原币证据只对授权管理员可见，不进入客户账单；
- 客户用量明细保留目录版本、模型、维度、用量、单价、报价积分和实际扣费；
- Excel 禁止公式、宏和未知列绕过，文件大小与行数受限。

## 15. 失败处理

- 模型清单读取失败：不生成部分静默草案，返回明确错误；
- 某供应商价格刷新失败：使用最后可信快照并标记待复核；
- 汇率缺失或过期：相关外币行不可发布，不复用不明汇率；
- 单位变化：视为高风险差异，必须人工确认；
- 导入中的身份字段与当前模型清单冲突：阻止对应行并展示差异；
- 已有目录时任何刷新或草案失败都不得中断现行客户调用；
- 全新安装在首份目录发布前继续 fail-closed。

## 16. 测试与验收

### 16.1 清单与匹配

- 已启用的百炼、火山等平台及已开通模型全部出现；
- 隐藏、禁用或不满足启用条件的平台不出现；
- 内置模型、额外模型、自定义映射及未匹配模型行为正确；
- 相似名称不能误匹配。

### 16.2 价格与 Excel

- 文本、图片、视频、音频、Embedding/重排多维度展开；
- 原币换算、1.5 倍售价、100 积分/元和安全底价计算准确；
- 三个工作表、只读字段、人工成本和风险提示完整；
- 空成本数据库仍能导出所有启用模型；
- 重复导入、非法单位、公式、宏、重复维度和篡改身份被阻止。

### 16.3 发布与运行时

- 缺价项默认阻止发布；
- 明确排除后可发布其余模型；
- 被排除模型返回模型未定价，已定价模型正常调用；
- 首份目录发布后不再全局返回 `catalog_not_ready`；
- 免费管理员调用保留报价与用量记录但不改变钱包和账本；
- 目录并发发布、请求锁定和历史不可变语义保持正确。

### 16.4 环境

- SQLite 单元和集成测试；
- 真实 PostgreSQL 的升级、并发审批和目录锁定测试；
- 管理 API 与前端流程测试；
- 使用模拟供应商，发布探测不产生真实外部调用或费用。

## 17. 实施顺序

1. 扩展版本化官方成本快照及严格模型映射；
2. 将启用模型清单与可信成本快照合并为草案；
3. 升级 Excel 三工作表、导入预检及默认 1.5 倍计算；
4. 实现缺价模型明确排除和模型级未定价错误；
5. 接入管理后台首次初始化向导；
6. 增加供应商价格候选适配器和刷新调度；
7. 完成 SQLite、真实 PostgreSQL 和端到端验收。

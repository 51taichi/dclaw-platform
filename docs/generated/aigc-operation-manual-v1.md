# DClaw AIGC 操作说明书

契约版本：1

## 从文字提示词创建视频素材

操作 ID：`aigc.text_to_video.create`，版本：`1`。

前置条件：

- 客户已经登录 DClaw，并从陆羽会话卡片进入当前 AIGC 素材任务。
- 当前任务状态不是已取消、已失效或已通过。
- DClaw 已配置至少一个可用的视频生成模型。

逐步操作：

### 1. 确认进入 AIGC 创意工作室

查看页面左侧菜单，确认“AIGC 创意工作室”已经高亮；如果没有高亮，点击左侧的“AIGC 创意工作室”。

- 控件：`nav.aigc-studio`
- 完成标志：页面中央出现画布区域，右侧持续显示当前任务操作助手。
- 找不到或操作失败：回到陆羽会话，点击当前素材任务卡片上的“继续制作”，不要从其他入口新建无绑定项目。

### 2. 创建当前任务项目

点击画布区域上方的“新建项目”，在弹窗中输入操作助手给出的项目名称，然后点击“创建”。

- 控件：`aigc.canvas.create`
- 完成标志：页面顶部显示新项目名称，画布为空且可以添加节点。
- 找不到或操作失败：如果已经自动打开绑定项目，跳过新建；如果按钮不可用，刷新页面后重新从任务卡片进入。

### 3. 添加视频生成节点

点击画布左侧圆形“+”按钮，在展开的节点菜单中点击“视频生成”，节点会放到当前画布。

- 控件：`aigc.toolbar.video-generate`
- 完成标志：画布中出现一个视频生成节点，节点右侧参数面板自动展开。
- 找不到或操作失败：确认当前没有选中其他节点；仍找不到时点击操作助手中的“重新定位当前控件”。

### 4. 粘贴视频提示词

点击右侧参数面板的“提示词”输入框，清空原内容，粘贴操作助手提供的完整提示词。

- 控件：`aigc.video.prompt-input`
- 完成标志：输入框完整显示提示词，且没有红色必填提示。
- 找不到或操作失败：点击操作助手中的“复制提示词”再次粘贴；不要自行删改镜头、主体和画面要求。

### 5. 选择指定模型

点击“生成模型”下拉框，选择操作助手指定的模型；不要改用外部平台或其他模型。

- 控件：`aigc.video.model-select`
- 完成标志：下拉框中显示指定模型名称，页面没有“模型不可用”提示。
- 找不到或操作失败：如果指定模型不在列表中，停止生成并点击操作助手中的“模型不可用”，让当前任务保持暂停。

### 6. 选择画面比例

点击“画面比例”，选择操作助手指定的比例；抖音竖版内容通常选择 9:16。

- 控件：`aigc.video.aspect-ratio-select`
- 完成标志：比例选项显示为指定值。
- 找不到或操作失败：如果模型不支持该比例，点击操作助手中的“参数不兼容”，不要自行替换比例。

### 7. 选择视频时长

点击“时长”，选择操作助手给出的秒数。

- 控件：`aigc.video.duration-select`
- 完成标志：时长选项显示为指定秒数。
- 找不到或操作失败：如果没有指定秒数，保持操作助手当前推荐值，不要选择更昂贵的最长时长。

### 8. 提交生成

再次核对提示词、模型、比例和时长，然后点击参数面板底部的“生成视频”。

- 控件：`aigc.video.generate-submit`
- 完成标志：节点显示排队中或生成中，并出现可识别的任务进度。
- 找不到或操作失败：如果按钮不可点击，按操作助手从上到下检查所有必填项；不要连续重复点击。

### 9. 确认生成结果

等待节点显示生成完成，点击播放按钮完整观看一次；确认画面可以正常播放后，点击操作助手中的“完成并返回会话”。

- 控件：`aigc.video.result-preview`
- 完成标志：视频资产已绑定到当前素材任务，任务状态变为“已完成”。
- 找不到或操作失败：生成失败时点击节点上的“查看原因”，按操作助手给出的恢复动作重试；离开页面不会丢失当前任务进度。

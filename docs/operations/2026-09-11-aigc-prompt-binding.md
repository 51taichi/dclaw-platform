# AIGC connected prompt bindings

Image and video jobs previously sent `${cover_prompt.text}` literally when a generated workflow stored it in the target node. The shared submission validator now resolves `text` references against directly connected prompt nodes in the authorized canvas, by physical node id or workflow logical id. Text edits are read on submission/retry; jobs retain the binding template and concrete prompt snapshot. Missing, ambiguous, disconnected, unfinished or cyclic references fail before provider submission.

Existing canvases remain compatible. Accepted remote tasks keep their original command and are only queried; updating a binding must not replay a paid operation. New/queued jobs persist the resolved body before execution. No existing assets are regenerated by deployment.

Validation: 239 router/AIGC tests passed, including image and Seedance request-body checks, changed upstream text, invalid bindings and cycles. Read-only resolution of both production tea-cup canvases matched their upstream text exactly (99 and 167 characters). No paid provider request was submitted for validation.

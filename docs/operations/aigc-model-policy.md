# AIGC 模型策略运维说明

## 生效范围

“设置 / 模型 / AIGC 创意工作室模型”分别管理生文、生图、生视频和音频四类模型。每一类独立保存，保存内容包括有序白名单和一个配置默认模型。

首次保存前，该分类处于“兼容模式”，AIGC Studio 继续展示所有满足现有发布、定价、供应商和适配器条件的模型。首次保存成功后，该分类切换为白名单模式，只有管理员选中的有效模型会对 AIGC Studio 可见并可提交。

## 模型状态

后台列表始终展示已识别的模型，包括不能选择的模型。不可选原因如下：

- `未定价`：当前有效零售目录中没有该供应商/模型的价格规则。
- `未发布`：模型未处于面向业务发布状态。
- `供应商未配置`：供应商缺少 API Key、Base URL 或其他必要配置。
- `供应商已停用`：管理员已停用该供应商。
- `暂不支持此适配器`：服务端没有该模型类别所需的运行适配器。
- `模型已不存在`：策略中保留的模型已经不在当前供应商模型清单中。

不可选模型会以灰色状态保留，不能新加入白名单，也不能设为默认。已经保存在策略中的失效模型不会被自动删除，便于定位配置变化并在条件恢复后自动复用。

## 配置默认与有效默认

“配置默认”是管理员明确保存的默认模型。“有效默认”是 AIGC Studio 当前实际用于新节点的默认模型。

当配置默认因停用、取消发布、取消定价或供应商不可用而失效时，系统保留配置默认，并临时使用白名单中排序最靠前的有效模型作为有效默认。原配置默认恢复有效后，会自动恢复为有效默认，无需管理员再次保存。

旧画布已保存的模型失效时，客户端仍展示原模型和“该模型已不可用”提示，不会静默改写画布。用户运行节点时必须明确确认切换到当前有效默认；确认后才更新节点并继续生成。服务端会在计费捕获和供应商调用之前再次校验白名单。

## 发布与回滚

正常发布时保持以下环境变量未设置或设为真：

```text
AIGC_MODEL_POLICY_ENFORCEMENT=true
```

需要紧急回滚模型策略过滤和提交校验时，将服务端环境变量设为以下任一明确假值并重启服务：

```text
AIGC_MODEL_POLICY_ENFORCEMENT=false
```

也接受 `0` 或 `off`。回滚开关只绕过 AIGC 模型策略，不修改供应商配置、模型发布/定价目录、计费公式、任务参数、画布数据或历史资产。排障完成后恢复为 `true` 并重启服务。

## 上线检查

1. 确认目标供应商已配置且启用。
2. 确认目标模型已发布并存在有效定价。
3. 依次保存四个分类；每类至少保留一个有效模型并明确默认项。
4. 在 AIGC Studio 新建四类节点，确认默认项、下拉范围和生成提交符合配置。
5. 临时使默认模型失效，确认有效默认回退；恢复条件后确认原默认自动恢复。
6. 打开包含旧失效模型的画布，确认系统提示并仅在用户确认后切换。

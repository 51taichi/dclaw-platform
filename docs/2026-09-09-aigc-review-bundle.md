# AIGC 整组素材审核提交

工作流通过 `review_node_ids` 声明有序的审核产物节点，独立于 `output_node_id`。模型负责选择组成最终作品的文案、图片、视频等节点。平台将逻辑节点映射到持久化的画布节点；前端收集这些节点当前产物，提交 `review_assets: [{node_id, asset_id}]`。同一节点有多个产物时全部保留。未生成产物的制作节点不能用上游提示词代替。

后端读取已声明范围内属于当前用户、画布及节点的实际资产，保留文字内容及各媒体输入，连同节点标识按顺序交给 Agent。可读文本文件（text/plain、text/markdown、application/json）以正文传入；媒体使用实际来源。审核质量、业务判断及结果仍由模型决定。

任务记录、事件负载及审核输入保存整组资产。`asset_id` 为兼容旧调用保留首项身份；它不代表整份作品。前端幂等键包含整组选项，重试相同提交复用同一键。审核任务的内容版本及工作流绑定继续沿用原身份。

陆羽同步事件中的整组资产，并把完整文字与媒体传入 S10/S11 主模型。审核结果绑定整组身份，reply 原文保留，不增加业务验收或修复模型调用。

未声明 `review_node_ids` 的已有工作流保持原单素材范围，不自动猜测或修改历史清单。要使用明确的整组范围，应由模型创建带清单的新工作流。只上传新 Agent 包不能更新 DClaw 提交接口或网页；必须同时发布服务端、网页和 Agent。本次修改尚未部署至生产。

验证：服务端相关单元与集成测试 197 项通过；包括真实文本读取、整组媒体进入模型调用、持久化与重复提交、原单媒体兼容。陆羽测试 207 项通过。前端提交、回执、向导及输出选择测试并通过 TypeScript 检查。测试不发起真实付费生成，未以生产会话作为通用测试数据。

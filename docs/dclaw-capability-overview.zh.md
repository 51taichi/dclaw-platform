# DClaw 能力说明文档

## 1. 产品定位

DClaw 是一个面向企业场景的 AI 工作台与多智能体执行平台。它将智能体、专家团队、任务执行、AIGC 创意生产、企业知识库、自动化任务、多端接入、开放 API 与后台治理能力整合在同一套可部署、可扩展、可审计的系统中。

DClaw 的目标不是只提供一个聊天窗口，而是把大模型能力沉淀为企业可持续使用的“智能执行力”：用户可以在工作台中发起任务、选择专家或技能、挂载业务资料、跟踪执行过程、复用执行结果；管理员可以统一管理模型、用户、权限、技能、插件、审计、存储和外部系统接入。

## 3. AI 工作台能力

DClaw 的 Workbench 是面向普通业务用户的任务入口。用户可以在工作台中描述目标、上传资料、选择专家或技能，并把一次对话升级为可追踪的任务执行流程。

主要能力包括：

- 发起任务：支持用户输入自然语言需求，附带文件、图片或业务资料。
- 选择执行对象：可选择单个专家、专家团队、技能或模型能力。
- 任务追踪：支持查看任务状态、运行进度、执行结果和历史记录。
- 结果复用：生成的内容、文件、图片、脚本、分析结果可以沉淀为后续任务的上下文。
- 多入口协作：同一类任务可以从控制台、小程序或外部 API 进入系统。

适用场景：

- 方案撰写、资料整理、报告生成。
- 客户问题分析、工单处理、售前售后辅助。
- 企业内部知识问答与流程辅助。
- 运营内容生成、素材整理和任务跟进。

## 4. 多智能体与专家团队

DClaw 支持把不同职责、不同上下文和不同工具权限的智能体配置为“专家”，并进一步组合为“专家团队”。

专家能力包括：

- 角色设定：为专家配置身份、职责、行为边界和工作方式。
- 模型配置：支持不同专家使用不同模型或模型供应商。
- 技能挂载：为专家挂载文件处理、浏览器、知识库、AIGC、自动化等技能。
- 工作区记忆：通过工作区与上下文管理，让专家在特定业务空间中持续工作。
- 工具权限控制：通过工具防护和运行约束降低误操作风险。

专家团队能力包括：

- 多角色协作：将研究、分析、撰写、审核、执行等角色拆分给不同专家。
- 复杂任务分解：支持一个任务在多个专家之间流转，形成协作式执行链路。
- 面向业务封装：把专家团队发布为业务能力，例如客服专家团、方案专家团、数据分析专家团。

## 5. AIGC Studio 创意生产能力

AIGC Studio 是 DClaw 的画布式创意生产空间，适合处理多素材、多步骤、多模型参与的生成任务。它不是简单的一次性图片生成页面，而是围绕“节点 + 资产 + 生成链路”的方式组织创意流程。

主要能力包括：

- 画布编排：在画布中组织文本、图片、视频、音频、脚本、参考资产等节点。
- 图片生成：支持文生图、图生图、多图生成、主图选择、风格模板和模型参数配置。
- 视频生成：支持视频节点、视频生成工作流和生成结果管理。
- 音频生成：支持音频节点及相关工作流。
- 脚本工作流：支持脚本节点、分镜解析、脚本结果展示和真实生产流程衔接。
- 参考资产：支持上传资产、引用已有资产、将文本引用加入 prompt。
- 长图导出：支持将内容组合为长图导出节点。
- 生成进度：支持后台运行 AIGC 任务并轮询完成状态，改善长任务体验。
- 资源访问：支持认证资源展示、媒体预览、下载和云端资源 URL 处理。

适用场景：

- 营销海报、商品图、社媒素材生产。
- 分镜脚本、短视频脚本和多模态内容策划。
- 基于参考图、风格模板和脚本文案的批量创意生成。
- 企业内容团队的素材生产与审核流转。

## 6. 企业知识与文件能力

DClaw 支持将企业知识、业务文档和任务文件纳入智能体工作流，使智能体不只依赖模型通用知识，而能够结合组织内部资料回答和执行。

主要能力包括：

- 知识库接入：支持知识资料管理、检索和引用。
- 文件处理：支持用户在任务中上传文件，并由智能体读取、分析和生成结果。
- 云文档与外部资料：可结合企业文档系统和云端资料扩展知识来源。
- 任务上下文沉淀：任务文件、执行结果和历史上下文可服务于后续工作。
- 结果产物管理：支持对生成文件、图片、报告、脚本等产物进行展示和筛选。

## 7. 技能、插件与工具扩展

DClaw 通过 Skills、MCP、插件和内置工具，让智能体从“会回答”扩展为“能执行”。

内置和可扩展能力包括：

- 文件读写与搜索。
- 浏览器控制与网页信息采集。
- 本地命令、安全沙箱和 Python 执行。
- 图片生成、演示文稿生成、媒体查看。
- 外部 Agent 委托执行。
- MCP 工具接入和 OAuth 授权。
- 技能市场、技能池、私有技能、技能发布范围管理。

这套扩展机制适合企业把内部工具、业务系统、知识服务、自动化脚本封装为智能体可调用的能力。

## 8. 自动化与协同

DClaw 支持将智能体能力从“用户主动发起”扩展到“系统自动触发”。

主要能力包括：

- 定时任务：支持周期性任务、一次性任务、执行历史和任务模板。
- 自动化页面：集中管理自动化任务和触发规则。
- 审批确认：关键操作可进入确认流程，降低自动执行风险。
- 收件箱：承载审批、推送、待处理事项和系统通知。
- 运行事件：记录任务执行过程中的事件和状态变化。

适用场景：

- 定时生成日报、周报、经营分析。
- 定期巡检系统、网页、数据或业务指标。
- 自动跟进客户、工单或审批事项。
- 需要人工确认后再继续执行的半自动流程。

## 9. 多端与多渠道接入

DClaw 不局限于 Web 控制台，而是提供多端、多渠道接入能力。

已覆盖的接入形态包括：

- Web 控制台：用于工作台、聊天、AIGC Studio、设置和后台管理。
- 微信小程序：面向移动端任务创建、任务查看、确认事项、工作台和个人中心。
- 企业 IM 渠道：包括钉钉、飞书、微信、企业微信等。
- 海外与开放渠道：包括 Telegram、Discord、Matrix、Mattermost 等。
- 语音与通信渠道：包括 Voice、SIP、iMessage、MQTT、OneBot、QQ 等扩展方向。

通过多端接入，企业可以把 DClaw 嵌入员工已经使用的工作入口，而不要求所有流程都回到单一控制台。

## 10. Open API 能力

DClaw 提供 Open API，用于将平台中的专家或专家团队发布给外部系统调用。

典型用法：

- 客服系统调用“客服专家”自动回复用户。
- CRM 或工单系统把客户问题发送给专家处理。
- 小程序、网站或 App 后端调用专家团队完成分析、整理和生成。
- 企业内部系统将 DClaw 作为智能体执行引擎。

Open API 关键能力：

- 发布对象：将专家或专家团发布为稳定的 Public ID。
- API Key 鉴权：为外部应用创建密钥，支持 scope 权限控制。
- 外部应用管理：区分不同调用方，便于审计、授权和撤销。
- IP allowlist：可限制调用来源，提高生产环境安全性。
- 调用审计：记录外部调用过程，便于排查和合规。
- 管理后台：提供 Open API 配置页面，支持发布、应用和密钥管理。

## 11. 模型与供应商管理

DClaw 支持企业统一管理模型供应商和模型能力，并将不同模型分配给不同业务场景。

主要能力包括：

- 多模型供应商配置。
- 远程模型管理。
- 本地模型接入。
- 模型能力识别与过滤。
- 聊天、AIGC、专家、技能等不同场景的模型选择。
- Token 用量统计与成本追踪。

这使企业可以按任务类型选择合适模型，例如通用对话使用高性价比模型，AIGC 使用专门图像或视频模型，复杂分析使用更强推理模型。

## 12. 管理、治理与安全能力

DClaw 面向企业部署，提供后台治理能力，帮助管理员控制系统边界和运行风险。

主要能力包括：

- 用户与认证：支持登录、用户管理、管理员能力和会话控制。
- 角色与权限：围绕专家、技能、Open API、后台配置进行权限隔离。
- 审计日志：记录关键操作和运行过程，便于追踪。
- Token 用量：统计模型调用消耗，辅助成本控制。
- 对象存储：支持云端资产、生成物和文件的存储管理。
- 备份恢复：支持配置与数据备份相关能力。
- 工具防护：对智能体可调用工具进行约束，降低高风险操作。
- 私有技能访问：支持技能发布范围和私有访问控制。

## 13. 部署与运维能力

DClaw 支持多种部署方式，适合从个人试用到企业私有化上线的不同阶段。

部署形态包括：

- 本地开发运行。
- pip / uv 安装运行。
- Docker Compose 部署。
- PostgreSQL / Redis 支撑的服务化部署。
- 控制台前后端一体化部署。
- 小程序独立构建与设备预览。

运维相关能力包括：

- 健康检查与版本接口。
- 配置管理和环境变量管理。
- 静态资源缓存。
- 数据库与对象存储配置。
- 日志、审计和运行事件追踪。

## 14. 典型业务场景

### 14.1 企业智能客服

企业可以创建客服专家或客服专家团，通过 Open API 接入客服系统、CRM 或工单平台。外部系统将用户问题发送给 DClaw，DClaw 结合专家配置、知识库和工具能力生成回复或处理建议。

### 14.2 内容营销与 AIGC 生产

运营团队可以在 AIGC Studio 中组织脚本、参考图、风格模板和生成节点，批量生成海报、商品图、短视频素材、长图和内容方案。

### 14.3 内部知识助手

企业可将规章制度、产品资料、项目文档、销售手册等沉淀到知识体系中，让员工通过控制台、小程序或 IM 直接提问和检索。

### 14.4 自动化办公助理

通过定时任务和自动化能力，DClaw 可以周期性生成日报、周报、巡检报告、客户跟进提醒，并在必要时进入审批确认流程。

### 14.5 多专家协同分析

对于方案、研究、尽调、竞品分析等复杂任务，可将任务拆分给多个专家：资料收集、结构分析、内容撰写、质量审核分别由不同专家完成。

## 15. 能力边界与使用建议

DClaw 适合作为企业内部 AI 执行平台、智能体中台和多端 AI 工作入口。为了获得更稳定的生产效果，建议：

- 为不同业务场景配置独立专家，而不是让一个通用智能体处理所有任务。
- 将高频任务沉淀为技能、专家团队或 Open API 发布对象。
- 将企业知识库、文件和业务系统工具纳入执行链路，减少模型凭空回答。
- 对外部系统调用使用服务端转发，不要把 API Key 暴露在前端、小程序或公开仓库。
- 对自动化和高风险工具启用审批、权限和审计。
- 在生产环境使用 PostgreSQL、Redis、对象存储和备份策略支撑稳定运行。

## 16. 总结

DClaw 的核心价值在于把大模型从“对话能力”升级为“企业可治理的执行能力”。它既提供面向用户的工作台和 AIGC 创意工具，也提供面向管理员和开发者的模型管理、技能扩展、Open API、多端接入与治理能力。

对于企业而言，DClaw 可以作为：

- AI 工作台；
- 多智能体协作平台；
- AIGC 创意生产平台；
- 企业知识与任务执行入口；
- 外部系统可调用的智能体 API 服务；
- 可私有化部署的 AI 应用底座。

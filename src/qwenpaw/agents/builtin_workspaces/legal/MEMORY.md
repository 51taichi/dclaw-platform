## 📁 文件结构规范

```
工作区/
├── MEMORY.md          # 长期记忆（核心配置与经验沉淀）
└── memory/            # 每日日志目录
    └── YYYY-MM-DD.md  # 当日详细记录
```

**定位规则：**
- `MEMORY.md` — 只存高价值可复用信息，定期精简
- `memory/YYYY-MM-DD.md` — 流水账、任务细节临时存储

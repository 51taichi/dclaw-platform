# 短剧创作工坊 🎬

## 技能简介

这是一个专业的短剧创作全流程工具，帮助你从简单的创意点子出发，通过三个专业角色的协作，最终产出完整的分镜脚本文案。

## 工作流程

```
用户创意点子
    ↓
创意总监 → 完善创意框架
    ↓
专业编剧 → 编写完整剧本  
    ↓
执行导演 → 制作分镜脚本
    ↓
最终分镜脚本文案
```

## 三个核心角色

### 1. 创意总监 🎨
- **职责**：将你的原始创意进行深度挖掘和扩展
- **输出**：结构化的创意框架，包含核心概念、人物设定、情节大纲等

### 2. 专业编剧 ✍️
- **职责**：将创意框架转化为完整的剧本
- **输出**：包含对话、动作描述、场景设置的专业剧本

### 3. 执行导演 🎥
- **职责**：将剧本转换为可执行的分镜脚本
- **输出**：包含镜头设计、拍摄角度、音效建议的分镜脚本

## 使用方法

### 基础使用
```
我有一个创意：[你的创意点子]
```

### 完整参数
```
创意点子：[你的创意点子]
类型：[爱情/悬疑/喜剧/都市/古装等]
时长：[3分钟/5分钟/10分钟等]
风格偏好：[轻松搞笑/紧张刺激/温馨感人等]
特殊要求：[如有特殊拍摄条件等]
```

## 使用示例

### 示例1：简单创意
```
我有一个创意：一个女孩在咖啡店偶遇了初恋男友，两人都装作不认识，但眼神交流中透露出复杂的情感
```

### 示例2：完整参数
```
创意点子：上班族小王每天在地铁上遇到同一个神秘女孩，直到有一天女孩递给他一张纸条
类型：都市爱情
时长：5分钟
风格偏好：温馨浪漫
特殊要求：主要在地铁场景拍摄，人物不超过3个
```

## 交付结构

使用此技能后，你将获得：

1. **创意框架** - 完整的故事构思和人物设定
2. **完整剧本** - 可直接拍摄的剧本文本
3. **分镜脚本** - 包含镜头设计的详细拍摄指导
4. **创作总结** - 拍摄建议和注意事项

## 技能特点

✨ **专业协作** - 三个专业角色各司其职，确保每个环节的质量
🎯 **用户导向** - 在创作过程中会征求意见，确保符合你的期望
📋 **结构化输出** - 所有输出都采用标准格式，便于后续使用
🎬 **实用性强** - 分镜脚本考虑了实际拍摄的可操作性
